# Calculator Program Rubric - CSE 232 (C)

## Requirements (100 points total)

### Functionality (50 points)
- All operations (+, -, *, /) work correctly (50 points)
- Most operations work with minor bugs (40 points)
- Some operations work (25 points)
- Program compiles but operations don't work (10 points)
- Doesn't compile (0 points)

### Error Handling (20 points)
- Proper handling of division by zero and invalid input (20 points)
- Some error handling (12 points)
- Minimal error handling (5 points)
- No error handling (0 points)

### Code Organization (15 points)
- Well-organized with separate functions for operations (15 points)
- Good organization with minor issues (10 points)
- Basic organization (5 points)
- Poor organization, everything in main() (0 points)

### Comments & Documentation (15 points)
- Clear comments explaining logic and function purposes (15 points)
- Good comments with minor gaps (10 points)
- Minimal comments (5 points)
- No comments (0 points)

## Grading Scale (BYU-Idaho Standard)
- A: 90-100
- B: 80-89
- C: 70-79
- D: 60-69
- F: Below 60
