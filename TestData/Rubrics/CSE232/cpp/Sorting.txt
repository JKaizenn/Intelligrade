# Sorting Algorithms Assignment Rubric - CSE 232

## Requirements (100 points total)

### Algorithm Implementation (50 points)
- All sorting algorithms correctly implemented and tested (50 points)
- All algorithms implemented with minor bugs (40 points)
- Most algorithms work but one or two have significant issues (30 points)
- Only basic algorithms implemented correctly (20 points)
- Algorithms fail to sort or do not compile (0 points)

### Test Coverage (20 points)
- Comprehensive test cases including edge cases (20 points)
- Good test coverage but missing some edge cases (15 points)
- Basic test cases only (10 points)
- No tests or minimal testing (0 points)

### Time Complexity Analysis (15 points)
- Correct analysis with detailed explanations for all algorithms (15 points)
- Mostly correct analysis with minor errors (10 points)
- Partial or incomplete analysis (5 points)
- No analysis provided or completely incorrect (0 points)

### Code Quality (15 points)
- Clean, well-documented, professional code (15 points)
- Good code with minor style issues (12 points)
- Acceptable but lacks documentation or has style problems (8 points)
- Poor quality, hard to read (0 points)

## Grading Scale (BYU-Idaho Standard)
- A: 90-100
- B: 80-89
- C: 70-79
- D: 60-69
- F: Below 60
