# Linked List Assignment Rubric - CSE 310

## Requirements (100 points total)

### Linked List Implementation (45 points)
- Complete linked list with all required methods (45 points)
- Most methods implemented correctly with minor bugs (35 points)
- Basic linked list with some functionality (25 points)
- Incomplete implementation (15 points)
- No working linked list (0 points)

### Memory Management (25 points)
- Perfect memory management with no leaks (25 points)
- Good memory management with minor issues (20 points)
- Some memory issues present (12 points)
- Significant memory leaks (5 points)
- Critical memory problems (0 points)

### Operations & Methods (20 points)
- All operations (add, remove, search, size) work correctly (20 points)
- Most operations work with minor issues (15 points)
- Basic operations only (10 points)
- Few operations working (5 points)
- No operations working (0 points)

### Code Quality (10 points)
- Professional code with excellent documentation (10 points)
- Good code quality (8 points)
- Acceptable code (5 points)
- Poor quality (0 points)

## Grading Scale (BYU-Idaho Standard)
- A: 90-100
- B: 80-89
- C: 70-79
- D: 60-69
- F: Below 60
