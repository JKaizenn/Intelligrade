# Linked List Assignment Rubric - CSE 310 (Java)

## Requirements (100 points total)

### Linked List Implementation (45 points)
- Complete generic linked list with all required methods (45 points)
- Most methods implemented correctly with minor bugs (35 points)
- Basic linked list with some functionality (25 points)
- Incomplete implementation (15 points)
- No working linked list (0 points)

### Java Best Practices (25 points)
- Excellent use of generics, proper encapsulation, follows Java conventions (25 points)
- Good Java code with minor issues (20 points)
- Functional but doesn't follow best practices (12 points)
- Poor code quality (0 points)

### JavaDoc & Documentation (15 points)
- Complete JavaDoc comments for all public methods and classes (15 points)
- Good documentation with minor gaps (10 points)
- Minimal documentation (5 points)
- No documentation (0 points)

### Testing (15 points)
- JUnit tests covering all methods and edge cases (15 points)
- Good test coverage (10 points)
- Basic tests (5 points)
- No tests (0 points)

## Grading Scale (BYU-Idaho Standard)
- A: 90-100
- B: 80-89
- C: 70-79
- D: 60-69
- F: Below 60
