# Binary Search Tree Assignment Rubric - CSE 310 (Python)

## Requirements (100 points total)

### BST Implementation (40 points)
- Complete BST with all operations (insert, search, delete, traverse) (40 points)
- Most operations implemented correctly with minor issues (30 points)
- Basic BST with some functionality (20 points)
- Incomplete implementation (10 points)
- No working implementation (0 points)

### Pythonic Implementation (20 points)
- Excellent use of Python features (magic methods, properties, iterators) (20 points)
- Good Python code with proper class structure (15 points)
- Functional but not Pythonic (10 points)
- Poor implementation (0 points)

### Type Hints & Documentation (20 points)
- Complete type hints and docstrings for all methods (20 points)
- Good type hints and documentation (15 points)
- Basic documentation (10 points)
- No documentation or type hints (0 points)

### Testing & Edge Cases (20 points)
- Comprehensive tests including edge cases (duplicate values, empty tree, etc.) (20 points)
- Good test coverage (15 points)
- Basic tests (10 points)
- No tests (0 points)

## Grading Scale (BYU-Idaho Standard)
- A: 90-100
- B: 80-89
- C: 70-79
- D: 60-69
- F: Below 60
