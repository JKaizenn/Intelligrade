# Custom Fonts (Optional)

IntelliGrade currently uses system default fonts:
- **macOS**: San Francisco
- **Windows**: Segoe UI
- **Linux**: System sans-serif

## To Use Libre Franklin (Optional)

If you want to use the Libre Franklin font:

1. Download from [Google Fonts](https://fonts.google.com/specimen/Libre+Franklin)
2. Place TTF files in this directory
3. Update `App.axaml` to reference the fonts

The app looks great with system fonts, so this is completely optional!
